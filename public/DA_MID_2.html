CH 3: MEDIAN & MODE OF GROUPED DATA

1. The Median of Grouped Data

You use this when data is in class intervals (e.g., 10-19, 20-29) and you need the exact middle value.

Median = L₁ + [ (n/2 - Cfb) / fm ] * C
  • L₁ = Lower class boundary of the median class.
  • n = Total frequency (sum of all f).
  • Cfb = Cumulative frequency of the class BEFORE the median class.
  • fm = Frequency of the median class itself.
  • C = Class size/width (Upper boundary - Lower boundary).

Step 1: Find the total frequency (n). Divide by 2 to find the median position.

Step 2: Look at the Cumulative Frequency (Cf) column. Find the first class where Cf is greater than or equal to n/2. This is your Median Class.

Step 3: Plug the values from that class into the formula.

2. The Mode of Grouped Data

The mode is the value that occurs most frequently. In grouped data, find the class with the highest frequency.

Mode = L₁ + [ Δ₁ / (Δ₁ + Δ₂) ] * C
  • L₁ = Lower class boundary of the modal class.
  • Δ₁ (Delta 1) = Frequency of Modal Class MINUS Frequency of the class BEFORE it.
  • Δ₂ (Delta 2) = Frequency of Modal Class MINUS Frequency of the class AFTER it.
  • C = Class width.

Step 1: Find the class with the highest frequency. This is your Modal Class.

Step 2: Calculate Δ₁ and Δ₂, then plug into the formula.

CH 4: RELATION BETWEEN TWO VARIABLES

1. Scatter Diagrams & Correlation (r)

  • Explanatory Variable (X): Plotted on the horizontal axis. It explains the changes.
  • Response Variable (Y): Plotted on the vertical axis. It is the outcome.
  • Linear Correlation Coefficient (r): Measures the strength and direction of the linear relation between X and Y.

Properties of 'r':

  • It is always between -1 and 1 inclusive. [-1, 1]
  • If r = +1, a perfect positive linear relation exists.
  • If r = -1, a perfect negative linear relation exists.
  • If r is close to 0, little to no linear relation exists.
  • CRITICAL: Correlation is NOT resistant to outliers. One extreme point can destroy 'r'.
  • CRITICAL: Correlation does NOT imply causation. Lurking variables (variables not measured in the study) might be causing the changes in both X and Y.

2. The Least-Squares Regression Line

This is the line that minimizes the sum of the squared errors (residuals). It is the "Line of Best Fit".

ŷ = b₁x + b₀
  • ŷ (y-hat) = The PREDICTED value of y.
  • b₁ (Slope) = r * (Sy / Sx). (Where Sy is std dev of y, Sx is std dev of x).
  • b₀ (Y-Intercept) = ȳ - b₁x̄. (Where ȳ is mean of y, x̄ is mean of x).

The Residual: The difference between the OBSERVED value (y) and the PREDICTED value (ŷ).

Formula: Residual = y - ŷ

3. Coefficient of Determination (R²)

This tells you how much of the variance in your response variable (Y) is actually explained by your explanatory variable (X).

  • If R² = 0.85, that means 85% of the variation in Y is explained by the least-squares regression line involving X.
  • R² is literally the square of the correlation coefficient (r) when dealing with simple linear regression. R² = (r)².
  • Range is 0 to 1 (or 0% to 100%).

4. Contingency Tables & Association

Used to relate two QUALITATIVE (categorical) variables. Think of a grid.

  • Marginal Distribution: A frequency or relative frequency distribution of EITHER the row or column variable in the contingency table. It ignores the other variable. (Formula: Row Total / Grand Total).
  • Conditional Distribution: Lists the relative frequency of each category of the response variable, GIVEN a specific category of the explanatory variable. (Formula: Cell Value / Row or Col Total).
  • If the conditional distributions are vastly different across categories, an association exists between the two variables.
