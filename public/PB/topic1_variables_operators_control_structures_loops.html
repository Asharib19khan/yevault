1. Variables & Data Types

In business programming, you must know exactly what kind of data you are holding. Data types determine what operations you can perform and how Python stores your values.

Integer (int): Whole numbers (e.g., transactions = 500)
Float (float): Decimals, crucial for money (e.g., balance = 150.75)
String (str): Text (e.g., customer_name = "Ali")
Boolean (bool): True or False flags (e.g., is_fraud = False)

🎯 The 100/100 Trap (Type Casting)

You cannot do math on a string. If a user inputs their age, Python reads it as text. You MUST cast it explicitly:

# EXPLICIT CASTING
raw_input = "5000"
deposit = int(raw_input)  # Now you can do math on it!
total = deposit + 1000
print(total)  # Output: 6000

2. Input, Output, and Operators

Basic I/O

  • input("Enter amount: ") always returns a string
  • print() displays output to the console

Arithmetic Operators

+

Addition: Adds two values together

5 + 3 = 8

-

Subtraction: Subtracts one value from another

10 - 4 = 6

*

Multiplication: Multiplies two values

7 * 6 = 42

/

Division: Always returns a float

10 / 2 = 5.0

**

Exponent/Power: Raises to a power

2 ** 3 = 8

//

Floor Division: Divides and drops decimal

10 // 3 = 3

The "Secret Weapon" Operators

// (Floor Division)

Divides and drops the decimal. 10 // 3 = 3

% (Modulo)

Gives you the remainder. 10 % 3 = 1

Extremely useful for finding even/odd numbers:

if num % 2 == 0:
    print("Even number")
else:
    print("Odd number")

3. Control Structures (The Brain)

This is how your program makes decisions based on conditions.

Relational Operators

==

Equal to

!=

Not equal to

>

Greater than

<

Less than

>=

Greater than or equal

<=

Less than or equal

Logical Operators

and

Both conditions must be true

or

At least one condition must be true

not

Reverses the boolean value

Real-World Example: Fraud Detection

# REAL EXAM LOGIC: Fraud Detection Condition
withdrawal = 50000
daily_limit = 20000
is_international = True

if withdrawal > daily_limit and is_international:
    print("Flag transaction for review!")
elif withdrawal > daily_limit:
    print("Send OTP to customer.")
else:
    print("Transaction approved.")

4. Loops (The Workhorse)

You use loops to repeat tasks without writing the same code 100 times.

Types of Loops

for Loops

Used when you know exactly how many times to repeat

while Loops

Used when you want to repeat until a condition changes

FOR LOOP Example: Compound Interest

Formula: A = P(1 + r)^t

# FOR LOOP: Calculating Compound Interest for 5 years
# Formula: A = P(1 + r)^t
principal = 1000
rate = 0.05

for year in range(1, 6):  # Loops from 1 to 5
    principal = principal + (principal * rate)
    print(f"Year {year} Balance: ${principal:.2f}")

# Output:
# Year 1 Balance: $1050.00
# Year 2 Balance: $1102.50
# Year 3 Balance: $1157.62
# Year 4 Balance: $1215.51
# Year 5 Balance: $1276.28

WHILE LOOP Example: Password Validation

# WHILE LOOP: Forcing correct user input
password = ""
while password != "Yeezus2026":
    password = input("Enter admin password: ")
    if password == "exit":
        break  # Emergency exit
    elif password != "Yeezus2026":
        print("Incorrect password. Try again.")

Loop Controls

break

Instantly exits the loop completely

continue

Skips current iteration and moves to next one

Practical Example: Skip Even Numbers

for num in range(1, 11):
    if num % 2 == 0:
        continue  # Skip even numbers
    print(num)

# Output: 1, 3, 5, 7, 9
