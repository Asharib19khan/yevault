PART 2 — Pandas (Data Manipulation)

What is Pandas?

Pandas is the library for working with tabular data — think Excel sheets, CSV files, databases — all in Python. It is built on top of NumPy.

import pandas as pd    # always as pd — standard convention

Two Core Data Structures

Series — 1D

s = pd.Series([10, 20, 30, 40])
print(s)
# 0    10
# 1    20
# 2    30
# 3    40
# dtype: int64

s = pd.Series([10, 20, 30], index=["a", "b", "c"])
print(s["a"])    # 10

DataFrame — 2D

data = {
    "Name":  ["Asharib", "Ali", "Sara"],
    "Age":   [20, 22, 21],
    "City":  ["Karachi", "Lahore", "Islamabad"],
    "Marks": [95, 88, 72]
}
df = pd.DataFrame(data)
print(df)
#       Name  Age       City  Marks
# 0  Asharib   20    Karachi     95
# 1      Ali   22     Lahore     88
# 2     Sara   21  Islamabad     72

Loading Data

# Read from CSV
df = pd.read_csv("students.csv")

# Read from Excel
df = pd.read_excel("students.xlsx")

# Save to CSV
df.to_csv("output.csv", index=False)

# Save to Excel
df.to_excel("output.xlsx", index=False)

Exploring a DataFrame

print(df.head())
print(df.head(3))
print(df.tail())
print(df.shape)
print(df.info())
print(df.describe())
print(df.columns)
print(df.dtypes)
print(len(df))

Important: df.shape returns a tuple of (rows, columns).

Selecting Data

Select a Column

print(df["Name"])
print(df[["Name", "Age"]])

Select Rows — .iloc

print(df.iloc[0])
print(df.iloc[1])
print(df.iloc[0:2])
print(df.iloc[0, 1])

Select Rows — .loc

print(df.loc[0])
print(df.loc[0, "Name"])
print(df.loc[df["Age"] > 20])

Note: iloc is integer position-based. loc is label-based or condition-based.

Filtering (Conditions)

print(df[df["Marks"] > 85])
print(df[(df["Marks"] > 80) & (df["Age"] < 90)])
print(df[df["City"] == "Karachi"])

Use & for AND and | for OR.

Sorting

df.sort_values("Marks")
df.sort_values("Marks", ascending=False)
df.sort_values(["Age", "Marks"], ascending=[True, False])

Aggregation and Grouping

print(df["Marks"].sum())
print(df["Marks"].mean())
print(df["Marks"].max())
print(df["Marks"].min())
print(df["Marks"].count())
print(df["Marks"].std())
print(df["Marks"].median())

Describe summary

print(df.describe())

Groupby

print(df.groupby("City")["Marks"].mean())
print(df.groupby("City")["Name"].count())
print(df.groupby("City").agg({"Marks": ["mean", "max", "min"]}))

Handling Missing Data

import numpy as np
print(df.isnull())
print(df.isnull().sum())

# Drop rows with any missing value
df.dropna()

# Drop rows where a specific column is missing
df.dropna(subset=["Marks"])

# Fill missing values
df.fillna(0)

df["Marks"].fillna(df["Marks"].mean())

df.fillna(method="ffill")

Note: NaN means missing or undefined data.

Adding / Modifying Columns

df["Grade"] = ["A", "B", "C"]
df["Marks_Doubled"] = df["Marks"] * 2
df["Pass"] = df["Marks"] >= 50

Dropping Columns / Rows

df.drop("Age", axis=1)
df.drop(["Age", "City"], axis=1)
df.drop(0, axis=0)

df.drop("Age", axis=1, inplace=True)

Short Answer Theory

What is a Series? A Series is a 1D labeled array (single column).

What is a DataFrame? A DataFrame is a 2D labeled structure like an Excel sheet.

What is NaN? NaN means missing or undefined data in a DataFrame.

Difference between iloc and loc? iloc selects by integer position. loc selects by label or condition.
