PART 1 — EXCEPTION HANDLING

What is an Exception?

When a program runs into an error during execution, Python raises an exception and the program can crash.

Without handling, the program dies. With handling, the program survives and responds gracefully.

print(10 / 0)
# ZeroDivisionError: division by zero

Note: There are two types of errors:

  • Syntax Error — wrong code structure, caught before running.
  • Exception — error that happens while running.

Common Built-in Exceptions

Exception When it happens
ZeroDivisionError Dividing by zero
ValueError Wrong value type, for example int("abc")
TypeError Wrong data type operation
NameError Using a variable that does not exist
IndexError Accessing an index that does not exist
KeyError Accessing a dictionary key that does not exist
FileNotFoundError Opening a file that does not exist
ImportError Importing a module that does not exist
AttributeError Using a method that does not exist on an object
OverflowError Number too large for Python to handle

The try / except Block

Basic structure:

try:
    # code that MIGHT cause an error
except:
    # code that runs IF an error occurs

Example:

try:
    num = int(input("Enter a number: "))
    result = 10 / num
    print("Result:", result)
except:
    print("Something went wrong!")

If the user enters 0 or "abc", the program prints the message instead of crashing.

Catching Specific Exceptions

try:
    num = int(input("Enter a number: "))
    result = 10 / num
    print(result)

except ZeroDivisionError:
    print("You can't divide by zero!")

except ValueError:
    print("That's not a valid number!")

Python checks each except block from top to bottom and runs the first match.

Multiple Exceptions in One Line

try:
    x = int(input("Enter: "))
    print(10 / x)

except (ValueError, ZeroDivisionError):
    print("Invalid input or division by zero!")

Catching the Exception Object

try:
    x = int("hello")

except ValueError as e:
    print("Error occurred:", e)

Example output:

Error occurred: invalid literal for int() with base 10: 'hello'

Exam tip: as e gives you the exact error description as a string.

The else Block

The else block runs only if no exception occurred.

try:
    num = int(input("Enter: "))
    result = 10 / num

except ZeroDivisionError:
    print("Can't divide by zero!")

except ValueError:
    print("Not a number!")

else:
    print("Success! Result is:", result)

Flow:

  • Error? → except runs, else is skipped.
  • No error? → else runs, except is skipped.

The finally Block

The finally block runs always, whether there was an error or not. It is used for cleanup like closing files.

try:
    f = open("data.txt", "r")
    content = f.read()

except FileNotFoundError:
    print("File not found!")

finally:
    print("This always runs no matter what.")

Note: finally runs even if there is a return statement in try or except.

Full Structure (All Four Blocks)

try:
    # risky code

except SpecificError:
    # handle specific error

except AnotherError:
    # handle another error

else:
    # runs if no error occurred

finally:
    # always runs (error or not)

Example:

try:
    age = int(input("Enter your age: "))
    print("Next year you'll be:", age + 1)

except ValueError:
    print("Please enter a valid number.")

else:
    print("Age recorded successfully.")

finally:
    print("Program finished.")

The raise Keyword

You can manually trigger an exception using raise. This stops the program and throws the exception you specify.

age = int(input("Enter age: "))

if age < 0:
    raise ValueError("Age cannot be negative")

Custom Exceptions (Theory)

You can create your own exception class by inheriting from Exception.

class NegativeAgeError(Exception):
    pass

age = int(input("Enter age: "))

if age < 0:
    raise NegativeAgeError("Age cannot be negative")

Just know the concept: inheriting from Exception creates a custom exception.

Practice Programs — Exception Handling

Safe Division:

try:

    b = int(input("Enter denominator: "))
    print(a / b)

Safe List Access:

my_list = [10, 20, 30]
try:
    index = int(input("Enter index: "))
    print(my_list[index])
except IndexError:
    print("Index out of range!")

Loop Until Valid Input:

while True:
    try:
        num = int(input("Enter a number: "))

    except ValueError:

print("You entered:", num)

PART 2 — FILE HANDLING (CSV)

What is File Handling?

File handling lets a Python program read from and write to files stored on the computer. Without file handling, all data is lost when the program ends.

Opening a File — open()

file = open("filename.txt", "mode")

Common file modes:

Mode Meaning
"r" Read — opens file for reading. Error if file does not exist.
"w" Write — creates file if not exists, overwrites if exists.
"a" Append — adds to end of file. Creates file if not exists.
"r+" Read + Write — file must exist.
"x" Create — creates file, error if already exists.

Add "b" for binary mode: "rb", "wb".

Reading a File

Method 1: read() reads the entire file as one string.

file = open("data.txt", "r")
content = file.read()
print(content)
file.close()

Method 2: readline() reads one line at a time.

file = open("data.txt", "r")
line1 = file.readline()
line2 = file.readline()
print(line1)
print(line2)
file.close()

Method 3: readlines() reads all lines into a list.

file = open("data.txt", "r")
lines = file.readlines()
print(lines)
file.close()

Method 4: Loop through lines.

file = open("data.txt", "r")
for line in file:
    print(line.strip())
file.close()

Writing to a File

file = open("output.txt", "w")
file.write("Hello, World!\n")
file.write("Second line\n")
file.close()
file = open("output.txt", "a")
file.write("This is added at the end\n")
file.close()

Always call file.close() after you are done. Otherwise data may not save properly.

The with Statement

The with statement automatically closes the file when done.

with open("data.txt", "r") as file:
    content = file.read()
    print(content)
with open("output.txt", "w") as file:
    file.write("Using with statement!\n")

The with statement is the recommended way to handle files.

CSV File Handling

A CSV file is comma separated values. Data is stored in rows and columns separated by commas.

import csv

Writing a CSV File with csv.writer

import csv

with open("students.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Name", "Age", "City"])
    writer.writerow(["Asharib", 20, "Karachi"])
    writer.writerow(["Ali", 22, "Lahore"])
    writer.writerow(["Sara", 21, "Islamabad"])

print("CSV file created!")

newline="" prevents extra blank lines in Windows.

Reading a CSV File with csv.reader

import csv

with open("students.csv", "r") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)

Output contains each row as a list.

Reading CSV with csv.DictReader

import csv

with open("students.csv", "r") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["Name"], row["Age"], row["City"])

DictReader uses the header row as keys.

Writing CSV with csv.DictWriter

import csv

fields = ["Name", "Age", "City"]
data = [
    {"Name": "Asharib", "Age": 20, "City": "Karachi"},
    {"Name": "Ali", "Age": 22, "City": "Lahore"}
]

with open("students.csv", "w", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=fields)
    writer.writeheader()
    writer.writerows(data)

print("Done!")

Appending to a CSV File

import csv

with open("students.csv", "a", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Zara", 19, "Karachi"])

print("Row added!")

File Handling and Exception Handling Combined

import csv

try:
    with open("students.csv", "r") as file:
        reader = csv.reader(file)
        for row in reader:
            print(row)

except FileNotFoundError:
    print("Error: The file does not exist!")

except Exception as e:
    print("Something went wrong:", e)

finally:
    print("File operation completed.")

import csv

highest = 0
top_student = ""

    reader = csv.DictReader(f)

Short Answer Theory

What is exception handling?

Exception handling is a mechanism to handle runtime errors gracefully using try, except, else, and finally blocks.

Difference between read(), readline(), and readlines()?

read() returns the whole file as one string. readline() returns one line at a time. readlines() returns a list where each item is one line.

Why use with open() instead of open()?

The with statement automatically closes the file after the block ends, even if an error occurs.

What is a CSV file?

A CSV file is a plain text file where data is stored in rows and columns separated by commas.

Difference between csv.reader and csv.DictReader?

csv.reader returns each row as a plain list. csv.DictReader returns each row as a dictionary using the header row as keys.

What does finally do?

The finally block always executes regardless of whether an exception occurred or not. It is used for cleanup like closing files.
